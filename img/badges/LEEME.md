# Insignias de certificaciones

Coloca aquí las insignias oficiales en PNG (de preferencia con fondo transparente, 300 × 300 px o más).
Si un archivo no existe, el portafolio muestra un marcador gris con las siglas.

| Archivo | Certificación |
|---|---|
| `pmp.png` | Profesional en Dirección de Proyectos (PMP) |
| `aws-cloud-practitioner.png` | AWS Certified Cloud Practitioner |
| `iso27001-lead-auditor.png` | ISO/IEC 27001:2022 Lead Auditor |
| `iso27001-implementer.png` | ISO/IEC 27001 Implementer |
| `iso27001-internal-auditor.png` | ISO/IEC 27001 Internal Auditor |
| `iso27001-udemy.png` | Sistemas de Gestión de Seguridad de la Información ISO 27001 |
| `itil4-foundation.png` | ITIL 4 Foundation |
| `scrum-fundamentals.png` | Scrum Fundamentals Certified (SFC) |
| `six-sigma-yellow-belt.png` | Six Sigma Yellow Belt (SSYB) |
| `cpmai.png` | Cognitive Project Management in AI (CPMAI) |
| `anbah-essentials.png` | ANBAH Essentials with IA |
| `power-platform-teams.png` | Power Platform y Teams (Net4skills) |
| `google-ia-productividad.png` | Google: Inteligencia Artificial y Productividad |
| `google-cloud-computing.png` | Cloud Computing (Google Actívate) |
| `windows-8-1.png` | Microsoft Windows 8.1 |

Para el botón **Verificar ↗**, pon la URL pública de la credencial (Credly, Accredible, etc.)
en el campo `verificar` de esa certificación dentro de `index.html`.
