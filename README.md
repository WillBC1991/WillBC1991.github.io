# Will · Portafolio

Portafolio personal de **Wilfrido Becerril**, Líder de TI, Desarrollo y Mejora Continua en BSD SmartPayroll.

Es un escritorio tipo sistema operativo que corre en el navegador: pantalla de bloqueo, inicio de sesión, ventanas que se arrastran, menú Inicio, terminal y fondo de estrellas animado. Se adapta a celular, tableta y PC.

## Cómo verlo

Abre `index.html` en el navegador. No necesita instalación ni servidor.

## Cómo editar el contenido

Todo el texto está al inicio del `<script>` en `index.html`:

- `PERFIL`: nombre, puesto, foto, correo, LinkedIn y GitHub
- `STACK`: tecnologías
- `PROYECTOS`: sistemas que aparecen en la app Proyectos
- `EXPERIENCIA`: línea de tiempo del currículum
